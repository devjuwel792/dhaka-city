## ১১. Simulation Functions

### ১১.১ `currentDetails` (লাইন 524–551)
Location-based multiplier + sine fluctuation:
- multiplier: Gulshan 1.15 · Dhanmondi 0.95 · Uttara 0.85 · Motijheel 1.25 · else 1.0
- fluctuation: `Math.sin(refreshTrigger) * 2`
- outputs: `temp, feelsLike, aqi, pm25, waterloggingRisk, cngAvailability{high,mod,low}, rickshawAvailability{high,mod,low}`

### ১১.২ `formatTemp / formatTempFull / formatTempNum` (লাইন 369–388)
C→F: `Math.round((celsius * 9) / 5 + 32)`

### ১১.৩ `filteredAlerts` (লাইন 628–637)
search (case-insensitive) + filter (all/good/minor/major)

### ১১.৪ Live clock (লাইন 394–409)
`setInterval(updateTime, 1000)`, locale `en-US`/`bn-BD`

### ১১.৫ Refresh trigger (লাইন 356–362)
`setInterval(..., refreshRate * 1000)` → `refreshTrigger++`

### ১১.৬ Canvas CCTV animation (লাইন 426–521)
প্রতি ৩৩ms: asphalt, road lines, ৬টি moving car + headlights, scanline, overlay text, REC dot। dependency `[activeTab, showCameraModal]`, cleanup `clearInterval`।

### ⚠️ Placeholder / stub handlers
| উপাদান | আচরণ |
|--------|-------|
| Logout button | `alert("Logged out successfully")` — আসল logout নেই |

### 🔁 Duplicated Logic
| বিষয় | কোথায় ডুপ্লিকেট |
|------|----------------|
| 5-day forecast array | Dashboard (~982) + Weather (~1344) — দুইবার hard-coded |
| Temperature conversion | Dashboard uses `formatTempFull`, Weather uses `currentDetails.temp + "° Celsius"` (hard-coded!) — অসঙ্গতি |
| Circular gauge SVG | App Rides, CNG, Rickshaw, Pollutants — ৪ জায়গায় একই pattern inline |
| Status dot + label | Alerts table, bus grid, legend — বারবার inline |
| Modal shell (overlay + close X) | ৪টি modal-এ একই markup |
| Forecast card markup | Dashboard + Weather |

### 🔧 Code smells / risks
- `w-4.5 h-4.5` (লাইন ~864, ~973) — Tailwind v4-এ `4.5` standard scale নাও থাকতে পারে (validation দরকার)।
- `via-green-400 via-yellow-400` (লাইন ~1427) — duplicate `via-` utility, একটা কাজ করবে না।
- `bg-emerald-450`, `text-gray-505`, `text-gray-605`, `border-gray-150` — non-standard color tokens, silently ignore হতে পারে।
- `animate-bounce animate-duration-3000` (লাইন ~946) — `animate-duration-*` Tailwind v4-এ unique নয় ( arbitrary `[3s]` দরকার হতে পারে)।
- একই `feed.id` দিয়ে Dashboard ও Live Street-এ canvas ref ওভাররাইট হওয়ার সম্ভাবনা।
- Forecast/hard-coded strings (যেমন `"13th of Dec"`, `"Cloudy"`) i18n নয় — বাংলা mode-এ English থাকে।
- `translations`-এ অনুবাদ না থাকা key (যেমন `"Traffic Now"`, `"Wind Speed"` inline) — partial i18n.

## ১৩. Responsive Implementation

- **Grid:** `grid-cols-1 xl:grid-cols-12`, `md:grid-cols-12`, `md:col-span-*`, `xl:col-span-*`।
- **Flex direction:** `flex-col md:flex-row`, `flex-col sm:flex-row`।
- **Sidebar:** fixed `w-[250px]` (কোনো mobile drawer/hamburger নেই — **mobile-এ sidebar পুরো জায়গা নিয়ে সমস্যা করতে পারে**)।
- **Header pills:** `flex items-center gap-3` — অনেকগুলো pill, mobile-এ wrap হয় না (overflow risk)।
- **Overall:** Desktop-first, responsive classes আছে কিন্তু sidebar/header mobile-এ সমস্যা।

## ১৪. Dark/Light Mode Implementation

- **মেকানিজম:** `isDark` React state (default `false`)।
- **প্রয়োগ:** root `<div>`-এ conditionally `bg-[#121212] text-gray-100` বনাম `bg-[#F4F6F8] text-gray-800`।
- **কার্ড/element:** শর্তসাপেক্ষ template class (`isDark ? "bg-[#1E1E1E] border-zinc-800" : "bg-white border-gray-200"`)।
- **কিছু জায়গায়** Tailwind `dark:` variant ব্যবহৃত (যেমন `dark:bg-emerald-950/20`) — কিন্তু `dark:` variant সক্রিয় করতে `darkMode: class` config বা `.dark` class প্রয়োজন; বর্তমানে `<html>`-এ `.dark` class বসানো হয় না, তাই `dark:` utility গুলো কাজ নাও করতে পারে (mixed approach)।
- **Persist:** কোনো localStorage/system-preference sync নেই।
